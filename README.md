# Global-GDP-Analysis-Dashboard
Dashboard project analyzing global GDP trends using data visualization.

## Overview
This project analyzes global GDP trends using different visualization techniques.

## Visualizations Used
- Packed Bubble Chart
- Line Chart
- Histogram
- Scatter Plot
- Stacked Bar Chart
- Tree Map
- Box Plot

- Excel / CSV Dataset
